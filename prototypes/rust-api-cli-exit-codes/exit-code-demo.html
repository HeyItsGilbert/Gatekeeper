Gatekeeper Rust — exit codes & observation events

Question this prototype answers (issue #101): how do the four Effect values (Allow/Deny/Audit/Warn) and the two fail-closed error classes (Definition/Context) show up on the CLI — as a process exit code, as stdout, and as the observation-hook events on stderr? This is the part that's easy to get wrong on paper: mid-list Audit/Warn never terminate, but a DefaultEffect of Audit/Warn does resolve to a final Deny (settled in #96) — so does that still count as "exit code 1", or does it need its own code?
